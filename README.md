# Planetopia

ინტერაქტიული მზის სისტემა ბავშვებისთვის. მზის გარშემო მოძრავი 8 პლანეტა და მათი მთვარეები საკუთარ ორბიტებზე, მარტივი ფაქტებით ქართულად.

## რა შეუძლია

- დააჭირე პლანეტას (რუკაზე ან ქვედა ზოლში) და ხედი მასზე გადავა, მისი მთვარეებით.
- თითოეულ პლანეტას და მთვარეს აქვს მოკლე, ბავშვისთვის გასაგები ფაქტები.
- პაუზა, სიჩქარე (½×, 1×, 3×, 8×) და ორბიტების ჩართვა/გამორთვა.
- მუშაობს ტელეფონზე და კომპიუტერზე.

მანძილები და ზომები მასშტაბში არ არის, რომ ყველაფერი ერთ ეკრანზე დაეტიოს. ორბიტების სიჩქარის თანაფარდობა რეალურ პერიოდებს მიჰყვება (შეკუმშული სახით).
